# Telegram Force Join Bot - Enhanced

Render Build Command:
pip install -r requirements.txt

Render Start Command:
python bot.py

Environment Variables:
BOT_TOKEN
ADMIN_ID
DATABASE_URL

Features:
- Welcome Bonus ₹1080
- Multiple force-join chats
- Custom join button titles
- Join verification before registration link
- Manual broadcast
- Daily scheduled broadcast (UTC)
- User statistics
- Leave/rejoin reminder when Telegram sends chat_member updates
- PostgreSQL persistence
- Render health endpoint

The bot must be an administrator in required chats for membership/leave updates.
